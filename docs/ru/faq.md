# Часто задаваемые вопросы

**В: С чего начать?**
О: Установите через Composer и ознакомьтесь с руководством
[Установка и настройка](installation.md).

**В: Как отправить сообщение?**
О: Подробные примеры см. в разделе [Использование клиента](use-client.md).

**В: Как обрабатывать входящие обновления?**
О: Настройку вебхука и обработчиков см. в разделе [Использование сервера](use-server.md).

**В: Какая версия PHP требуется?**
О: PHP 8.2 или выше.

**В: Какое корневое пространство имён у библиотеки?**
О: Всё находится под `UzDevid\Telegram\Bot\*` — например, `UzDevid\Telegram\Bot\Client`,
`UzDevid\Telegram\Bot\Server`, `UzDevid\Telegram\Bot\Message\Message\Method\*`.

**В: Как запустить статический анализ?**
О: Выполните `composer static-analysis`, чтобы запустить PHP_CodeSniffer, PHPStan и PHP-CS-Fixer
вместе. Отдельные команды см. в разделе [Внесение вклада](contributing.md).

**В: Есть ли документация для каждого метода?**
О: Да — у каждого класса метода есть полный блок PHPDoc с официальным описанием Telegram и `@link`
на официальную документацию. Полный список см. в разделе [Методы API](api-methods.md).

**В: Как я могу внести свой вклад?**
О: Рекомендации см. в разделе [Внесение вклада](contributing.md).
