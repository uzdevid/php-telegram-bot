# Frequently Asked Questions

## English

### Q: How do I get started?
**A:** Install via Composer and check the [Installation & Configuration](installation.md) guide.

### Q: How do I send a message?
**A:** See [Using the Client](use-client.md) for detailed examples.

### Q: How do I handle incoming updates?
**A:** See [Using the Server](use-server.md) for webhook and polling setups.

### Q: Which PHP version is required?
**A:** PHP 8.2 or higher is required.

### Q: Can I use this with my existing Telegram bot?
**A:** Yes, this library provides an alternative way to interact with the Telegram Bot API.

### Q: How do I run static analysis?
**A:** Run `composer static-analysis` to run all checks. See [Static Analysis](static-analysis.md) for details.

### Q: Is there documentation for each method?
**A:** Yes, every method has comprehensive PHPDoc with official descriptions. See [API Methods](api-methods.md).

### Q: How do I contribute?
**A:** See [Contributing](contributing.md) for guidelines.
